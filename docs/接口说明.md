# 创游助手 · 接口说明

## 一、HTTP API（src/server.py）

服务默认监听 `127.0.0.1:8765`，所有接口返回 JSON（UTF-8），支持跨域。

| 方法 | 路径 | 请求体 | 响应 |
|---|---|---|---|
| GET | `/api/health` | - | `{"ok":true,"service":"创游助手 GameForge","version":"1.0.0"}` |
| GET | `/api/status` | - | 系统状态：需求/事务/快照数、哈希链校验、当前配置、版本列表 |
| GET | `/api/memory` | - | 全部需求账本（id / text / time） |
| GET | `/api/versions` | - | 全部版本快照 |
| GET | `/api/demo.html` | - | 返回零依赖演示界面 |
| POST | `/api/chat` | `{"requirement":"把主角改成粉色"}` | 完整协作 trace：steps / config / report / snapshot / generated_files |
| POST | `/api/rollback` | `{"version":1}` | 回滚结果：ok / version / config / time |

## 二、核心工具接口（src/engine.py，供智能体调用）

| 工具 | 输入 | 输出 | 异常 |
|---|---|---|---|
| `tool_memory_recall(keyword)` | 检索词（可空） | 命中的需求列表（带引用） | 无命中返回空列表 |
| `tool_edit_config(config, ops)` | 新配置 + 变更说明 | 更新后配置 | 参数越界由自检钳制 |
| `tool_gen_godot(config)` | 游戏配置 | 生成文件清单 + 脚本/场景内容 | 目录不可写抛 IOError |
| `tool_selfcheck(config, gen)` | 配置 + 生成产物 | 自检报告（健康分/修复项/结论） | - |
| `tool_snapshot(config, label, desc)` | 配置 + 标签 | 快照记录（含内容寻址 addr） | - |

## 三、主编排器接口

```python
engine.run(requirement)   # 接收玩家意见，执行完整协作，返回 trace
engine.rollback(version)  # 回滚到指定版本
engine.status()           # 查询系统状态
```
