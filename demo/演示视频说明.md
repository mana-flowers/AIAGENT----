# 演示视频说明

> 附件3要求：演示视频 ≤5 分钟、分辨率 ≥1080P、画面须包含系统**真实运行过程**，不得剪辑伪造。

## 视频获取方式

本仓库 `demo.html` 为真实可运行的演示界面。演示视频由参赛队按 `答辩演示脚本.md` 的
5 分钟脚本，对真实运行界面进行**屏幕录制**生成，不经剪辑拼接。

**录制步骤：**
1. 双击 `demo/demo.html`（Chrome / Edge 全屏 F11）。
2. 用 OBS 或系统自带录屏（Win+G），分辨率设为 1920×1080。
3. 按 `答辩演示脚本.md` 逐幕操作并讲解：
   开场定位 → 从零生成 → 改成粉色+加速 → 看自检报告 → 问"我之前提过哪些要求" → 回滚到 v1 → 结束。
4. 导出 MP4，命名建议：`学院-队名-项目名称-演示视频.mp4`。

## 为什么用屏幕录制而非预渲染

规程禁止"使用剪辑拼接伪造效果；视频中须出现系统界面与交互过程"。
屏幕录制真实反映多智能体协作日志滚动、游戏实时变色、自检报告生成、版本回滚画面变化，
是对"真实运行过程"要求的直接满足。答辩现场亦可现场操作复核。

## 备注

- 若最终视频文件 >50MB，按附件3要求**不直接入库**，改用网盘链接 + 提取码方式在 README 或提交材料中提供。
- 视频链接可在报名表的"预期成果—演示视频"处勾选并附链接。
