# data — 脱敏数据与知识库文档

本目录存放本项目使用的知识库文档与配置数据，均**无真实个人隐私、无保密信息、无真实密钥**。

## 内容清单

| 文件 | 说明 | 来源 |
|---|---|---|
| 需求账本样例 | 玩家意见样例（如"把主角改成粉色"），全部为虚构演示数据 | 本项目构造 |
| 游戏配置参数 | 颜色/速度/重力/跳跃力等游戏参数，非敏感数据 | 本项目构造 |
| 意图词典 | 颜色词、动作词的映射词典 | 本项目构造 |

## 来源与脱敏说明

- 所有玩家意见均为**虚构演示数据**，不涉及任何真实用户。
- 未使用任何外部数据集；未采集真实用户数据。
- 知识库切分策略、检索与重排方案、引用溯源机制详见 `docs/项目设计与开发方案-创游助手.docx` 第 4 章。
- 运行中生成的需求/事务/快照状态存放于 `state/`，已通过 `.gitignore` 排除，不入库。
