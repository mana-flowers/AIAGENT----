# 创游助手 GameForge

> 用 Python 脚本操控 **Godot 4** 游戏引擎、听懂玩家意见并自动改写游戏的 AI 智能体。
> 验证项目《史莱姆勇者》——脚本代码、美术、音效、动画全部由智能体**程序化创作**。
> 北京科技大学 2026「人工智能创新应用」校赛参赛作品。

---

## 1. 项目简介与业务场景

普通 AI 编程助手是"一次性代码补全"，玩家提完意见就断档，改坏游戏也无法回退。**创游助手**解决的是：
**"游戏生成之后，如何被玩家持续地、可控地修改"**。

面向游戏开发场景，它把玩家的自然语言意见，变成**可追溯、可自检、可回滚**的真实 Godot 工程变更：

| 核心能力 | 机制 |
|---|---|
| 🧠 记住所有要求、随时调用 | 需求账本 RequirementLedger（append-only + 检索溯源） |
| 🔍 自检自查、自动纠偏 | 质检 Agent + SelfChecker（6 静态规则 + 3 运行探针） |
| 🕰️ 随时回滚 | 内容寻址快照 + 哈希链事务（SnapshotStore + TransactionChain） |
| 🎮 操控 Godot 4 | godot_gen 自动生成 .gd / .tscn / .svg / .wav，可直接导入引擎 |
| 🎨 全程序化创作 | SVG 像素美术 + Web Audio/WAV 音效，零外部素材 |

技术路线：**感知 → 规划 → 记忆 → 工具 → 执行** 五层架构，主从式多智能体（Master + 规划/代码/美术/质检 4 Worker）。

## 2. 环境要求与安装步骤

- **Python** ≥ 3.8（仅用标准库，无需 pip 安装即可运行内核）
- **Godot** ≥ 4.0（可选，用于打开生成的 `godot_project/`）
- **浏览器**（Chrome / Edge，用于查看零依赖演示界面）

```bash
# 拉取仓库
git clone <仓库地址>
cd AIAGENT-学院简称-队名

# 无第三方依赖，直接运行
python main.py --selftest     # 内核自检（应 5 项全绿）
```

## 3. 配置说明

**模型网关**：默认采用 **mock 模式**（内置意图解析器），答辩现场不依赖网络与真实密钥，保证 100% 稳定。
如需切换真实大模型，在 `src/engine.py` 的 LLM 网关处填入：

```
MODEL_GATEWAY_URL  = <你的模型网关地址>
MODEL_API_KEY      = <从环境变量读取，例如 os.environ["GAMEFORGE_API_KEY"]>
```

> ⚠️ **不得提交真实密钥**。本仓库不含任何密钥；密钥一律通过环境变量注入，`.gitignore` 已排除本地配置文件。

## 4. 运行与演示步骤

**方式 A · 零依赖演示（答辩首选，双击即开）**
```

```
内置完整多智能体协作动画、可游玩的《史莱姆勇者》、需求账本、自检报告、版本回滚。

（若启动动画卡顿，点击画面任意处跳过，或在网址后加 `#noboot`。）

```bash
python main.py --selftest
```
验证：首次生成 / 意见修改 / 玩法增强 / 记忆调用 / 版本回滚五项全绿。

```bash
python main.py
```

## 5. 功能清单与已知限制

**功能清单**
- 自然语言需求解析（颜色 / 速度 / 跳跃 / 场景 / 玩法 / 记忆查询）
- 主从式多智能体协作（规划 / 代码 / 美术 / 质检）
- 需求账本：全量留存 + 关键词检索 + 引用溯源
- 自检自查：6 静态规则 + 3 运行探针，异常自动修复（如速度越界自动钳制）
- 版本回滚：SHA-256 内容寻址快照 + 哈希链事务，一键恢复任意版本
- Godot 4 工程生成：脚本 / 场景 / SVG 美术 / WAV 音效
- 可观测结构化日志：每一步执行可追溯

**已知限制**
- 当前为演示原型，意图解析采用规则式 mock，未接入真实大模型（接口已预留）。
- 游戏模板为横版动作固定玩法，可扩展更多品类。
- 评测指标为目标值 + 测量方法，实测数据需按 `eval/` 评测集完整跑批后填充。
