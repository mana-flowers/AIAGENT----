# eval — 评测集、评测脚本与评测报告

> 对应附件3仓库结构 `eval/` 目录，以及方案书 5.4 节的 6 项量化指标。

## 目录说明

本目录用于存放：
- 评测任务集（24 个评测任务卡）
- 评测脚本（自动跑分）
- 评测报告（实测结果）

## 6 项量化指标与测量方法

| 指标 | 定义 | 测量方法 |
|---|---|---|
| 意图识别准确率 | 正确解析的需求数 / 总需求数 | 评测集标注意图，比对 parser 输出 |
| 生成成功率 | 成功生成可运行工程次数 / 总生成次数 | 调用自检健康分≥80 判定成功 |
| 自检命中率 | 检出注入缺陷数 / 注入缺陷总数 | 注入 N 个已知缺陷，统计检出数 |
| 回滚一致性 | 回滚后配置与目标快照哈希相同的比例 | 比对 content-address |
| P95 响应延迟 | 95% 请求的端到端耗时 | 打点统计 100 次请求 |
| 需求召回率 | 检索命中需求数 / 应命中需求数 | 构造检索 query + 标准答案 |

## 一键自检

在仓库根目录运行（等价于评测冒烟测试）：

```bash
python main.py --selftest
```

当前原型内置内核自检（生成/修改/增强/记忆/回滚五项），结果见控制台输出。
正式评测时，把 24 个评测任务卡与实测报告补充进来即可。
